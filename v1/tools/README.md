# tools/

Letakkan `chromedriver.exe` di folder ini. Versinya harus sama dengan Google Chrome di komputer Anda.
Unduh dari https://googlechromelabs.github.io/chrome-for-testing/ lalu salin sebagai `v1/tools/chromedriver.exe`.
Scraper membaca path ini (`tools/chromedriver.exe`), jadi jalankan aplikasi dari folder `v1/`.
Berkas ini tidak di-commit karena ukurannya ±19 MB (lihat `.gitignore`).
